# v0.4 — Edição básica + arquivo de projeto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Editar a timeline (blade, lift, ripple delete, mover com ímã, insert/overwrite a partir do viewer de fonte com In/Out), desfazer/refazer qualquer edição e salvar/abrir o projeto com autosave e backups.

**Architecture:** Operações de edição são **funções puras** em `mcs_core` (`Timeline` → `EditResult`), testadas com timelines em texto. Novo `mcs_edit` com `TimelineDocument`: o **ponto único de edição** — aplica um `EditResult` como passo de `QUndoStack` (snapshot antes/depois). UI, atalhos e, no futuro, o servidor MCP (Subprojeto 7) passam todos por ele. O projeto (`.mcsproj`, JSON versionado) é lido/gravado em `mcs_core` com `QSaveFile` e backups rotativos; `MainWindow` cuida de abrir/salvar/autosave.

**Tech Stack:** C++20, Qt 6.11.3 (Core, Gui — `QUndoStack` —, Widgets, Concurrent, Test), FFmpeg 9.0.2 e miniaudio via vcpkg.

**Spec:** [docs/superpowers/specs/2026-10-13-mcs-ai-editor-design.md](../specs/2026-10-13-mcs-ai-editor-design.md) — marco v0.4 (seção 9, atualizado em 2026-10-14), seção 7 (modelo, 7.1 operações, 7.4 arquivo de projeto), seção 8 (atalhos), seção 10 (testes em tabela).

## Decisões deste plano

- **Linked Selection (Ctrl+Shift+L, ligada por padrão):** vídeo e o áudio que veio junto compartilham `Clip::link`. Ligada, clicar seleciona o par; desligada, seleciona só o clipe clicado (ex.: apagar só o áudio do vídeo). As **operações não expandem a seleção** — mexem exatamente nos ids recebidos; quem expande é a timeline (pedido do Miguel em 2026-10-14).
- **Volume por clipe (`Clip::gainDb`)**: Ctrl+Alt+= / Ctrl+Alt+− (±1 dB, faixa −60…+12 dB) nos clipes de áudio selecionados; o mixer aplica o ganho. Slider e keyframes de volume ficam no Inspector do v0.6. Ouvir dois áudios ao mesmo tempo (trilha A2) fica para o v0.5; no v0.4 um arquivo só de áudio com F10 **substitui** o trecho em A1 sem tocar no vídeo.
- **Sync lock implícito:** insert e ripple delete deslocam **todas** as trilhas, para nunca dessincronizar vídeo e áudio. Ripple delete recusa (com mensagem) quando outra trilha tem clipe não selecionado no intervalo.
- **Mover = overwrite no destino** (comportamento padrão do Resolve); nunca antes do quadro 0. Só horizontal (há uma trilha de cada tipo no v0.4).
- **Undo por snapshot da timeline inteira** (`QUndoStack`, limite 200 passos). *Teto conhecido:* memória em timelines enormes; upgrade = trilhas compartilhadas (`shared_ptr`) como na spec 7.
- **Projeto guarda caminhos absolutos** das mídias. *Teto conhecido:* mover a pasta do projeto quebra os links; upgrade = caminho relativo ao `.mcsproj` + relink. Mídia ausente ao abrir: o projeto abre, o clipe fica offline (preto/silêncio) e a lista de arquivos faltando aparece num aviso.
- **Autosave** a cada 2 min quando há mudanças: `<projeto>.autosave` ou, sem projeto salvo, `AppDataLocation/autosave/untitled.mcsproj`. Recuperação automática ao abrir fica para depois (o arquivo abre por File > Open).
- **Pronto para MCP:** nenhuma edição altera a timeline fora do `TimelineDocument::apply`.

#include "support/timeline_text.h"

#include <QMap>
#include <QRegularExpression>
#include <QStringList>

namespace mcs::test {

core::Timeline parseTimeline(const QString& text) {
    core::Timeline t;
    t.video.clear();
    t.audio.clear();
    QMap<QString, QUuid> links;
    static const QRegularExpression clipRe(QStringLiteral(R"(^(\w+)\[(\d+)\.\.(\d+)\)(?:@(\d+))?$)"));
    for (const QString& part : text.split(QLatin1Char('|'))) {
        const QString trimmed = part.trimmed();
        const qsizetype colon = trimmed.indexOf(QLatin1Char(':'));
        const QString header = trimmed.left(colon);
        const bool video = header.startsWith(QLatin1Char('V'));
        const auto index = static_cast<std::size_t>(header.mid(1).toInt() - 1);
        auto& tracks = video ? t.video : t.audio;
        if (tracks.size() <= index) {
            tracks.resize(index + 1);
        }
        const QString body = trimmed.mid(colon + 1).trimmed();
        if (body == QLatin1String("-")) {
            continue;
        }
        for (const QString& token : body.split(QLatin1Char(' '), Qt::SkipEmptyParts)) {
            const auto m = clipRe.match(token);
            Q_ASSERT_X(m.hasMatch(), "parseTimeline", qPrintable(token));
            const QString name = m.captured(1);
            QUuid& link = links[name.toLower()];
            if (link.isNull()) {
                link = QUuid::createUuid();
            }
            const std::int64_t start = m.captured(2).toLongLong();
            const std::int64_t end = m.captured(3).toLongLong();
            tracks[index].clips.push_back(core::Clip{QUuid::createUuid(), name, {25, 1}, start,
                                                     end - start, m.captured(4).toLongLong(), link,
                                                     0.0});
        }
    }
    if (t.video.empty()) {
        t.video.resize(1);
    }
    if (t.audio.empty()) {
        t.audio.resize(1);
    }
    return t;
}

QString formatTimeline(const core::Timeline& timeline) {
    QStringList parts;
    auto formatTracks = [&](const std::vector<core::Track>& tracks, QChar kind) {
        for (std::size_t i = 0; i < tracks.size(); ++i) {
            QStringList clips;
            for (const core::Clip& c : tracks[i].clips) {
                QString s = QStringLiteral("%1[%2..%3)").arg(c.path).arg(c.start).arg(c.end());
                if (c.sourceIn != 0) {
                    s += QStringLiteral("@%1").arg(c.sourceIn);
                }
                clips << s;
            }
            parts << QStringLiteral("%1%2: %3")
                         .arg(kind)
                         .arg(i + 1)
                         .arg(clips.isEmpty() ? QStringLiteral("-") : clips.join(QLatin1Char(' ')));
        }
    };
    formatTracks(timeline.video, QLatin1Char('V'));
    formatTracks(timeline.audio, QLatin1Char('A'));
    return parts.join(QStringLiteral(" | "));
}

QSet<QUuid> idsOf(const core::Timeline& timeline, const QString& name) {
    QSet<QUuid> ids;
    for (const auto* tracks : {&timeline.video, &timeline.audio}) {
        for (const core::Track& track : *tracks) {
            for (const core::Clip& c : track.clips) {
                if (c.path == name) {
                    ids.insert(c.id);
                }
            }
        }
    }
    return ids;
}

} // namespace mcs::test

QSet<QUuid> select(const mcs::core::Timeline& t, const QString& names) {
    QSet<QUuid> ids;

        QVERIFY(!r.error.isEmpty());

#include "core/edit_ops.h"

#include <QCoreApplication>
#include <QFileInfo>
#include <algorithm>
#include <map>
#include <utility>
#include <vector>

namespace mcs::core {

namespace {

QString tr(const char* text) {
    return QCoreApplication::translate("mcs::core", text);
}

template <typename T> auto tracksOf(T& timeline) {
    std::vector<decltype(&timeline.video[0])> out;
    for (auto& t : timeline.video) {
        out.push_back(&t);
    }
    for (auto& t : timeline.audio) {
        out.push_back(&t);
    }
    return out;
}

// Parte direita de um clipe cortado em `frame` (start < frame < end). Clipes ligados cortados
// juntos recebem o mesmo link novo nas partes direitas (via `rightLinks`).
Clip rightPart(const Clip& c, std::int64_t frame, Rational fps, std::map<QUuid, QUuid>& rightLinks) {
    Clip r = c;
    r.id = QUuid::createUuid();
    if (!c.link.isNull()) {
        auto [it, inserted] = rightLinks.try_emplace(c.link);
        if (inserted) {
            it->second = QUuid::createUuid();
        }
        r.link = it->second;
    }
    r.sourceIn = sourceFrameAt(c, frame, fps);
    r.start = frame;
    r.duration = c.end() - frame;
    return r;
}

} // namespace

const Clip* findClip(const Timeline& timeline, const QUuid& id) {
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (c.id == id) {
                return &c;
            }
        }
    }
    return nullptr;
}

QSet<QUuid> withLinked(const Timeline& timeline, const QSet<QUuid>& ids) {
    QSet<QUuid> links;
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (ids.contains(c.id) && !c.link.isNull()) {
                links.insert(c.link);
            }
        }
    }
    QSet<QUuid> out = ids;
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (!c.link.isNull() && links.contains(c.link)) {
                out.insert(c.id);
            }
        }
    }
    return out;
}

EditResult blade(const Timeline& timeline, std::int64_t frame) {
    Timeline r = timeline;
    std::map<QUuid, QUuid> rightLinks;
    bool cut = false;
    for (Track* track : tracksOf(r)) {
        std::vector<Clip> out;
        for (const Clip& c : track->clips) {
            if (c.start < frame && frame < c.end()) {
                Clip left = c;
                left.duration = frame - c.start;
                out.push_back(left);
                out.push_back(rightPart(c, frame, r.fps, rightLinks));
                cut = true;
            } else {
                out.push_back(c);
            }
        }
        track->clips = std::move(out);
    }
    if (!cut) {
        return {std::nullopt, tr("There is no clip under the playhead to cut.")};
    }
    return {r, {}};
}

EditResult lift(const Timeline& timeline, const QSet<QUuid>& ids) {
    if (ids.isEmpty()) {
        return {std::nullopt, tr("Select one or more clips first.")};
    }
    Timeline r = timeline;
    for (Track* track : tracksOf(r)) {
        std::erase_if(track->clips, [&](const Clip& c) { return ids.contains(c.id); });
    }
    return {r, {}};
}

EditResult rippleDelete(const Timeline& timeline, const QSet<QUuid>& ids) {
    std::vector<std::pair<std::int64_t, std::int64_t>> ranges;
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (ids.contains(c.id)) {
                ranges.emplace_back(c.start, c.end());
            }
        }
    }
    if (ranges.empty()) {
        return {std::nullopt, tr("Select one or more clips first.")};
    }
    std::sort(ranges.begin(), ranges.end());
    std::vector<std::pair<std::int64_t, std::int64_t>> merged;
    for (const auto& range : ranges) {
        if (!merged.empty() && range.first <= merged.back().second) {
            merged.back().second = std::max(merged.back().second, range.second);
        } else {
            merged.push_back(range);
        }
    }
    // Outra trilha com clipe no intervalo: fechar a lacuna sobreporia esse clipe.
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (ids.contains(c.id)) {
                continue;
            }
            for (const auto& [s, e] : merged) {
                if (c.start < e && c.end() > s) {
                    return {std::nullopt,
                            tr("Ripple delete would move clips over \"%1\". Select it too or use "
                               "Delete.")
                                .arg(QFileInfo(c.path).fileName())};
                }
            }
        }
    }
    Timeline r = timeline;
    for (Track* track : tracksOf(r)) {
        std::erase_if(track->clips, [&](const Clip& c) { return ids.contains(c.id); });
        for (Clip& c : track->clips) {
            std::int64_t shift = 0;
            for (const auto& [s, e] : merged) {
                if (e <= c.start) {
                    shift += e - s;
                }
            }
            c.start -= shift;
        }
    }
    return {r, {}};
}

void clearRange(Track& track, std::int64_t s, std::int64_t e, Rational fps,
                std::map<QUuid, QUuid>& rightLinks) {
    std::vector<Clip> out;
    for (const Clip& c : track.clips) {
        if (c.end() <= s || c.start >= e) {
            out.push_back(c);
            continue;
        }
        if (c.start < s) {
            Clip left = c;
            left.duration = s - c.start;
            out.push_back(left);
        }
        if (c.end() > e) {
            out.push_back(rightPart(c, e, fps, rightLinks));
        }
    }
    track.clips = std::move(out);
    sortTrack(track);
}

    clearRange(track, clip.start, clip.end(), fps, rightLinks);

    sortTrack(track);

    std::int64_t minStart = -1;
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            if (ids.contains(c.id)) {
                minStart = minStart < 0 ? c.start : std::min(minStart, c.start);
            }
        }
    }
    if (minStart < 0) {
        return {std::nullopt, tr("Select one or more clips first.")};
    }
    delta = std::max(delta, -minStart);
    Timeline r = timeline;
    std::map<QUuid, QUuid> rightLinks;
    for (Track* track : tracksOf(r)) {
        std::vector<Clip> moved;
        for (const Clip& c : track->clips) {
            if (ids.contains(c.id)) {
                moved.push_back(c);
            }
        }
        std::erase_if(track->clips, [&](const Clip& c) { return ids.contains(c.id); });
        for (Clip c : moved) {
            c.start += delta;
            place(*track, c, r.fps, rightLinks);

std::int64_t snapDelta(const Timeline& timeline, const QSet<QUuid>& ids, std::int64_t delta,
                       std::int64_t playhead, std::int64_t threshold) {
    std::vector<std::int64_t> targets{0, playhead};
    std::vector<std::int64_t> edges;
    for (const Track* track : tracksOf(timeline)) {
        for (const Clip& c : track->clips) {
            auto& list = ids.contains(c.id) ? edges : targets;
            list.push_back(c.start);
            list.push_back(c.end());
        }
    }
    std::int64_t best = delta;
    std::int64_t bestDistance = threshold + 1;
    for (const std::int64_t edge : edges) {
        for (const std::int64_t target : targets) {
            const std::int64_t d = target - (edge + delta);
            if (std::abs(d) < bestDistance) {
                bestDistance = std::abs(d);
                best = delta + d;
            }
        }
    }
    return best;
}

            if (ids.contains(c.id)) {
                c.gainDb = std::clamp(c.gainDb + deltaDb, kMinGainDb, kMaxGainDb);
                changed = true;
            }
        }
    }
    if (!changed) {
        return {std::nullopt, tr("Select an audio clip to change its volume.")};
    }
    return {r, {}};
}

namespace mcs::edit {

// ponytail: snapshot da timeline inteira por passo (limite 200); trilhas compartilhadas
// (shared_ptr) se timelines muito grandes pesarem na memória.
class SnapshotCommand : public QUndoCommand {
public:
    SnapshotCommand(TimelineDocument* document, const QString& text, core::Timeline before,
                    core::Timeline after)
        : QUndoCommand(text), document_(document), before_(std::move(before)),
          after_(std::move(after)) {}

    void undo() override { document_->setTimeline(before_); }
    void redo() override { document_->setTimeline(after_); }

private:
    TimelineDocument* document_;
    core::Timeline before_;
    core::Timeline after_;
};

TimelineDocument::TimelineDocument(QObject* parent) : QObject(parent) {
    stack_.setUndoLimit(200);
}

const core::Timeline& TimelineDocument::timeline() const {
    return timeline_;
}

QString TimelineDocument::apply(const QString& actionName, const core::EditResult& result) {
    if (!result.timeline) {
        return result.error;
    }
    stack_.push(new SnapshotCommand(this, actionName, timeline_, *result.timeline));
    return {};
}

void TimelineDocument::reset(const core::Timeline& timeline) {
    stack_.clear();
    setTimeline(timeline);
    stack_.setClean();
}

QUndoStack* TimelineDocument::undoStack() {
    return &stack_;
}

bool TimelineDocument::isModified() const {
    return !stack_.isClean();
}

void TimelineDocument::markSaved() {
    stack_.setClean();
}

void TimelineDocument::setTimeline(const core::Timeline& timeline) {
    timeline_ = timeline;
    emit timelineChanged();
}

#include "core/project_file.h"

#include <QCoreApplication>
#include <QFile>
#include <QFileInfo>
#include <QJsonArray>
#include <QJsonDocument>
#include <QJsonObject>
#include <QSaveFile>

namespace mcs::core {

namespace {

QString tr(const char* text) {
    return QCoreApplication::translate("mcs::core", text);
}

QJsonArray rationalToJson(Rational r) {
    return QJsonArray{static_cast<qint64>(r.num), static_cast<qint64>(r.den)};
}

Rational rationalFromJson(const QJsonValue& value) {
    const QJsonArray a = value.toArray();
    return normalized({a.at(0).toInteger(), a.at(1).toInteger(1)});
}

QJsonObject clipToJson(const Clip& c) {
    return QJsonObject{{QStringLiteral("id"), c.id.toString(QUuid::WithoutBraces)},
                       {QStringLiteral("path"), c.path},
                       {QStringLiteral("sourceFps"), rationalToJson(c.sourceFps)},
                       {QStringLiteral("start"), static_cast<qint64>(c.start)},
                       {QStringLiteral("duration"), static_cast<qint64>(c.duration)},
                       {QStringLiteral("sourceIn"), static_cast<qint64>(c.sourceIn)},
                       {QStringLiteral("link"), c.link.toString(QUuid::WithoutBraces)},
                       {QStringLiteral("gainDb"), c.gainDb}};
}

Clip clipFromJson(const QJsonObject& o) {
    return Clip{QUuid::fromString(o.value(QStringLiteral("id")).toString()),
                o.value(QStringLiteral("path")).toString(),
                rationalFromJson(o.value(QStringLiteral("sourceFps"))),
                o.value(QStringLiteral("start")).toInteger(),
                o.value(QStringLiteral("duration")).toInteger(),
                o.value(QStringLiteral("sourceIn")).toInteger(),
                QUuid::fromString(o.value(QStringLiteral("link")).toString()),
                o.value(QStringLiteral("gainDb")).toDouble(0.0)};
}

QJsonArray tracksToJson(const std::vector<Track>& tracks) {
    QJsonArray out;
    for (const Track& t : tracks) {
        QJsonArray clips;
        for (const Clip& c : t.clips) {
            clips.append(clipToJson(c));
        }
        out.append(clips);
    }
    return out;
}

std::vector<Track> tracksFromJson(const QJsonValue& value) {
    std::vector<Track> tracks;
    for (const QJsonValue& track : value.toArray()) {
        Track t;
        for (const QJsonValue& clip : track.toArray()) {
            t.clips.push_back(clipFromJson(clip.toObject()));
        }
        tracks.push_back(std::move(t));
    }
    if (tracks.empty()) {
        tracks.resize(1);
    }
    return tracks;
}

QString backupPath(const QString& path, int n) {
    return path + QStringLiteral(".bak%1").arg(n);
}

} // namespace

QByteArray projectToJson(const Project& project) {
    const QJsonObject timeline{{QStringLiteral("fps"), rationalToJson(project.timeline.fps)},
                               {QStringLiteral("video"), tracksToJson(project.timeline.video)},
                               {QStringLiteral("audio"), tracksToJson(project.timeline.audio)}};
    const QJsonObject root{{QStringLiteral("app"), QStringLiteral("MCS AI Editor")},
                           {QStringLiteral("schemaVersion"), kProjectSchemaVersion},
                           {QStringLiteral("media"), QJsonArray::fromStringList(project.media)},
                           {QStringLiteral("timeline"), timeline}};
    return QJsonDocument(root).toJson(QJsonDocument::Indented);
}

ProjectLoad projectFromJson(const QByteArray& json) {
    QJsonParseError parse{};
    const QJsonDocument doc = QJsonDocument::fromJson(json, &parse);
    if (parse.error != QJsonParseError::NoError || !doc.isObject()) {
        return {std::nullopt, tr("This is not a valid project file (%1).").arg(parse.errorString())};
    }
    const QJsonObject root = doc.object();
    const int version = root.value(QStringLiteral("schemaVersion")).toInt(0);
    if (version < 1 || !root.value(QStringLiteral("timeline")).isObject()) {
        return {std::nullopt, tr("This is not a valid project file.")};
    }
    if (version > kProjectSchemaVersion) {
        return {std::nullopt,
                tr("This project was saved by a newer version of MCS AI Editor.")};
    }
    const QJsonObject timeline = root.value(QStringLiteral("timeline")).toObject();
    Project p;
    for (const QJsonValue& m : root.value(QStringLiteral("media")).toArray()) {
        p.media << m.toString();
    }
    p.timeline.fps = rationalFromJson(timeline.value(QStringLiteral("fps")));
    if (p.timeline.fps.num <= 0) {
        return {std::nullopt, tr("This is not a valid project file (frame rate).")};
    }
    p.timeline.video = tracksFromJson(timeline.value(QStringLiteral("video")));
    p.timeline.audio = tracksFromJson(timeline.value(QStringLiteral("audio")));
    return {p, {}};
}

bool saveProject(const QString& path, const Project& project, QString* error, int backups) {
    if (backups > 0 && QFileInfo::exists(path)) {
        QFile::remove(backupPath(path, backups));
        for (int i = backups; i > 1; --i) {
            QFile::rename(backupPath(path, i - 1), backupPath(path, i));
        }
        QFile::copy(path, backupPath(path, 1));
    }
    QSaveFile file(path);
    if (!file.open(QIODevice::WriteOnly) || file.write(projectToJson(project)) < 0 ||
        !file.commit()) {
        if (error) {
            *error = tr("Cannot save \"%1\": %2").arg(QFileInfo(path).fileName(), file.errorString());
        }
        return false;
    }
    return true;
}

ProjectLoad loadProject(const QString& path) {
    QFile file(path);
    if (!file.open(QIODevice::ReadOnly)) {
        return {std::nullopt, tr("Cannot open \"%1\".").arg(QFileInfo(path).fileName())};
    }
    return projectFromJson(file.readAll());
}

#include "core/edit_ops.h"

TimelineView::TimelineView(QWidget* parent) : QWidget(parent) {
    setObjectName(QStringLiteral("timelineView"));
    setMinimumHeight(kRulerHeight + 2 * kTrackHeight);
    setToolTip(tr("Timeline: click a clip to select it, drag to move; click the ruler to move the "
                  "playhead"));
}

void TimelineView::setTimeline(const core::Timeline* timeline) {
    timeline_ = timeline;
    update();
}

void TimelineView::setPlayhead(std::int64_t frame) {
    playhead_ = std::max<std::int64_t>(0, frame);
    update();
}

std::int64_t TimelineView::playhead() const {
    return playhead_;
}

void TimelineView::setPixelsPerFrame(double ppf) {
    ppf_ = std::max(0.05, ppf);
    update();
}

double TimelineView::pixelsPerFrame() const {
    return ppf_;
}

std::int64_t TimelineView::frameAtX(int x) const {
    return std::max<std::int64_t>(0, std::llround((x - kHeaderWidth) / ppf_));
}

int TimelineView::xForFrame(std::int64_t frame) const {
    return kHeaderWidth + static_cast<int>(std::lround(static_cast<double>(frame) * ppf_));
}

QSize TimelineView::sizeHint() const {

}

void TimelineView::setSelection(const QSet<QUuid>& ids) {
    if (ids == selection_) {
        return;

    emit selectionChanged();
    update();
}

QSet<QUuid> TimelineView::selection() const {
    return selection_;
}

    snapping_ = on;
}

bool TimelineView::snapping() const {
    return snapping_;
}

void TimelineView::setLinkedSelection(bool on) {
    linkedSelection_ = on;
}

bool TimelineView::linkedSelection() const {
    return linkedSelection_;

const core::Track* TimelineView::trackAtY(int y) const {
    if (!timeline_ || y < kRulerHeight) {
        return nullptr;
    }
    const auto row = static_cast<std::size_t>((y - kRulerHeight) / kTrackHeight);
    if (row < timeline_->video.size()) {
        return &timeline_->video[row];
    }
    const std::size_t audioRow = row - timeline_->video.size();
    return audioRow < timeline_->audio.size() ? &timeline_->audio[audioRow] : nullptr;
}

QUuid TimelineView::clipAt(QPoint pos) const {
    const core::Track* track = trackAtY(pos.y());
    if (!track) {
        return {};
    }
    const auto frame = static_cast<std::int64_t>(std::floor((pos.x() - kHeaderWidth) / ppf_));
    const core::Clip* clip = core::clipAt(*track, frame);
    return clip ? clip->id : QUuid();
}

std::int64_t TimelineView::dragDeltaFor(int x) const {
    const std::int64_t raw = std::llround((x - dragOriginX_) / ppf_);
    if (!snapping_ || !timeline_) {
        return raw;
    }
    const auto threshold = std::max<std::int64_t>(1, std::llround(kSnapPixels / ppf_));
    return core::snapDelta(*timeline_, selection_, raw, playhead_, threshold);
}

void TimelineView::paintEvent(QPaintEvent*) {
    QPainter p(this);
    p.fillRect(rect(), QColor(0x18, 0x18, 0x18));

    // Régua: um traço por segundo.
    p.fillRect(QRect(0, 0, width(), kRulerHeight), QColor(0x22, 0x22, 0x22));
    p.setPen(QColor(0x80, 0x80, 0x80));
    const std::int64_t fpsNominal =
        std::max<std::int64_t>(1, std::llround(timeline_ ? timeline_->fps.toDouble() : 25.0));
    for (std::int64_t f = 0; xForFrame(f) < width(); f += fpsNominal) {
        p.drawLine(xForFrame(f), kRulerHeight - 6, xForFrame(f), kRulerHeight);
    }

    const std::size_t videoTracks = timeline_ ? timeline_->video.size() : 1;
    const std::size_t audioTracks = timeline_ ? timeline_->audio.size() : 1;
    auto drawTrack = [&](int row, const QString& label, const core::Track* track, QColor color) {
        const int y = kRulerHeight + row * kTrackHeight;
        p.setPen(QColor(0x30, 0x30, 0x30));
        p.drawLine(0, y + kTrackHeight - 1, width(), y + kTrackHeight - 1);
        p.setPen(QColor(0xc0, 0xc0, 0xc0));
        p.drawText(QRect(0, y, kHeaderWidth, kTrackHeight), Qt::AlignCenter, label);
        if (!track) {
            return;
        }
        for (const core::Clip& clip : track->clips) {
            const bool selected = selection_.contains(clip.id);
            const std::int64_t offset = (selected && drag_ == Drag::Clips) ? dragDelta_ : 0;
            const QRect r(xForFrame(clip.start + offset), y + 3,
                          std::max(1, xForFrame(clip.end()) - xForFrame(clip.start)),
                          kTrackHeight - 6);
            p.fillRect(r, selected ? color.lighter(140) : color);
            if (selected) {
                p.setPen(QPen(QColor(0xe0, 0x7a, 0x2e), 2));
                p.drawRect(r.adjusted(1, 1, -1, -1));
            }
            p.setPen(QColor(0x10, 0x10, 0x10));
            p.drawText(r.adjusted(4, 0, -2, 0), Qt::AlignVCenter | Qt::AlignLeft,
                       QFileInfo(clip.path).fileName());
            if (clip.gainDb != 0.0) {
                p.drawText(r.adjusted(4, 0, -4, 0), Qt::AlignVCenter | Qt::AlignRight,
                           tr("%1 dB").arg(clip.gainDb, 0, 'f', 1));
            }
        }
    };
    int row = 0;
    for (std::size_t i = 0; i < videoTracks; ++i) {
        drawTrack(row++, QStringLiteral("V%1").arg(i + 1),
                  timeline_ ? &timeline_->video[i] : nullptr, QColor(0x4a, 0x7d, 0xb8));
    }
    for (std::size_t i = 0; i < audioTracks; ++i) {
        drawTrack(row++, QStringLiteral("A%1").arg(i + 1),
                  timeline_ ? &timeline_->audio[i] : nullptr, QColor(0x4f, 0xa8, 0x6a));
    }

    p.setPen(QPen(QColor(0xe0, 0x4a, 0x3a), 2));
    p.drawLine(xForFrame(playhead_), 0, xForFrame(playhead_), height());
}

void TimelineView::moveTo(int x) {
    const std::int64_t frame = frameAtX(x);
    setPlayhead(frame);
    emit playheadMoved(frame);
}

void TimelineView::mousePressEvent(QMouseEvent* event) {
    if (event->button() != Qt::LeftButton) {
        return;
    }
    const QPoint pos = event->position().toPoint();
    const QUuid id = pos.y() >= kRulerHeight ? clipAt(pos) : QUuid();
    if (id.isNull()) {
        if (pos.y() >= kRulerHeight) {
            setSelection({});
        }
        drag_ = Drag::Playhead;
        moveTo(pos.x());
        return;
    }
    const QSet<QUuid> linked =
        linkedSelection_ ? core::withLinked(*timeline_, {id}) : QSet<QUuid>{id};
    if (event->modifiers() & Qt::ControlModifier) {
        QSet<QUuid> next = selection_;
        if (selection_.contains(id)) {
            next.subtract(linked);
        } else {
            next.unite(linked);
        }
        setSelection(next);
        drag_ = Drag::None;
        return;
    }
    if (!selection_.contains(id)) {
        setSelection(linked);
    }
    drag_ = Drag::Clips;
    dragOriginX_ = pos.x();
    dragDelta_ = 0;
}

void TimelineView::mouseMoveEvent(QMouseEvent* event) {
    if (!(event->buttons() & Qt::LeftButton)) {
        return;
    }
    const int x = event->position().toPoint().x();
    if (drag_ == Drag::Playhead) {
        moveTo(x);
    } else if (drag_ == Drag::Clips) {
        dragDelta_ = dragDeltaFor(x);
        update();
    }
}

void TimelineView::mouseReleaseEvent(QMouseEvent* event) {
    if (event->button() != Qt::LeftButton) {
        return;
    }
    if (drag_ == Drag::Clips && dragDelta_ != 0) {
        emit clipsMoveRequested(selection_, dragDelta_);
    }
    drag_ = Drag::None;
    dragDelta_ = 0;
    update();
}

} // namespace mcs::ui

std::optional<core::SourceRange> EditPage::sourceRange(QString* error) const {
    const QModelIndex index = list_->currentIndex();
    if (!index.isValid()) {
        *error = tr("Select a clip in the Media Pool first.");
        return std::nullopt;
    }
    const core::MediaInfo& info = pool_->item(index.row()).info;
    core::SourceRange r;
    r.path = info.path;
    r.video = info.video.has_value();
    r.audio = info.audio.has_value();
    if (info.video && info.video->fps.num > 0) {
        r.sourceFps = info.video->fps;
        r.in = viewer_->inPoint().value_or(0);
        r.out = viewer_->outPoint() ? *viewer_->outPoint() + 1 : info.video->frameCount;
    } else {
        r.sourceFps = document_->timeline().fps;
        r.out = std::llround(info.durationSeconds * r.sourceFps.toDouble());
    }
    return r;
}
