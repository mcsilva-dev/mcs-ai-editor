# v0.1 — Esqueleto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repositório compilável em C++20 + Qt 6.11.3 + FFmpeg (vcpkg) com uma janela principal (páginas Edit/Deliver, tema escuro), testes Qt Test passando localmente no Windows e CI configurado para Windows/Linux/macOS.

**Architecture:** CMake + Ninja com presets; dependências C/C++ via vcpkg em modo manifesto (baseline fixado); Qt via `aqtinstall` em `C:\Qt`. Bibliotecas estáticas por módulo (`mcs_media`, `mcs_ui`) e um executável fino (`mcs_ai_editor`). Testes Qt Test registrados no CTest, rodando com `QT_QPA_PLATFORM=offscreen`.

**Tech Stack:** C++20, MSVC 14.52 (VS 2026), Qt 6.11.3 (`msvc2022_64`), FFmpeg 9.0.2 via vcpkg (baseline `e456309491fd875487bf02b8a0dca76c1b1b00cc`), CMake ≥ 3.25, Ninja, clang-format 22.1, GitHub Actions.

**Spec:** [docs/superpowers/specs/2026-10-13-mcs-ai-editor-design.md](../specs/2026-10-13-mcs-ai-editor-design.md) — marco v0.1 (seção 9) + seções 4, 10, 11, 12.

- C++20, sem extensões de compilador (`CMAKE_CXX_EXTENSIONS OFF`).
- Avisos como erro: MSVC `/W4 /WX /permissive- /utf-8`; GCC/Clang `-Wall -Wextra -Wpedantic -Werror`.
- Qt **6.11.3** exatamente (versão fixada — QRhi tem compatibilidade limitada entre versões).
- vcpkg modo manifesto, `builtin-baseline` `e456309491fd875487bf02b8a0dca76c1b1b00cc`.
- Textos de UI em inglês, sempre via `tr()`.
- Commits: Conventional Commits, mensagem terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Texto com acento no código-fonte** (`"Edição"`): sem `/utf-8` o MSVC lê o fonte como cp1252 e corrompe a string → teste em Task 3 (`tst_toolchain::utf8SourceEncoding`).
2. **Executável aberto direto da pasta de build (duplo clique)** deve iniciar sem "Qt6Core.dll não encontrado" → `windeployqt` pós-build + teste `app_starts` com PATH sem Qt (Task 4).
3. **Rodar sem tela (CI/servidor)**: testes de janela precisam funcionar headless → `QT_QPA_PLATFORM=offscreen` em todo teste Qt Test (Task 2/4); `app_starts` usa offscreen fora do Windows.
4. **Windows em tema claro**: o app deve ser escuro independente do tema do SO → `tst_mainwindow::darkThemeIndependentOfOs` (Task 4).
5. **Quebra de linha CRLF em scripts/YAML** quebraria Linux/macOS no CI → `.gitattributes` + verificação `git ls-files --eol` (Task 1).

namespace mcs::ui {

void applyDarkTheme(QApplication& app) {
    app.setStyle(QStyleFactory::create(QStringLiteral("Fusion")));

    QPalette p;

MainWindow::MainWindow(QWidget* parent) : QMainWindow(parent) {
    setWindowTitle(tr("MCS AI Editor %1").arg(QStringLiteral(MCS_VERSION)));
    setMinimumSize(1280, 720);

    auto* central = new QWidget(this);
    auto* layout = new QVBoxLayout(central);
    layout->setContentsMargins(0, 0, 0, 0);
    layout->setSpacing(0);

    pages_ = new QStackedWidget(central);
    pageBar_ = new QWidget(central);
    auto* barLayout = new QHBoxLayout(pageBar_);
    barLayout->setContentsMargins(0, 4, 0, 4);
    barLayout->addStretch();
    pageButtons_ = new QButtonGroup(this);
    pageButtons_->setExclusive(true);

    layout->addWidget(pages_, 1);
    layout->addWidget(pageBar_);
    setCentralWidget(central);

    addPage(QStringLiteral("edit"), tr("Edit"));
    addPage(QStringLiteral("deliver"), tr("Deliver"));
    barLayout->addStretch();

    showPage(QStringLiteral("edit"));
}

void MainWindow::addPage(const QString& name, const QString& label) {
    auto* page = new QLabel(label, pages_);
    page->setObjectName(QStringLiteral("page_") + name);
    page->setAlignment(Qt::AlignCenter);
    pages_->addWidget(page);

    auto* button = new QToolButton(pageBar_);
    button->setObjectName(QStringLiteral("pageButton_") + name);
    button->setText(label);
    button->setCheckable(true);
    button->setToolTip(tr("Open the %1 page").arg(label));
    pageButtons_->addButton(button, static_cast<int>(names_.size()));
    pageBar_->layout()->addWidget(button);
    connect(button, &QToolButton::clicked, this, [this, name] { showPage(name); });

    names_.append(name);
}

QStringList MainWindow::pageNames() const { return names_; }

QString MainWindow::currentPage() const { return names_.value(pages_->currentIndex()); }

void MainWindow::showPage(const QString& name) {
    const auto index = names_.indexOf(name);
    if (index < 0) {
        return;
    }
    pages_->setCurrentIndex(static_cast<int>(index));
    pageButtons_->button(static_cast<int>(index))->setChecked(true);
}

name: ci

on:

env:
