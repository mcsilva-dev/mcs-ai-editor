# v0.3 — Timeline + playback com áudio sincronizado Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Montar uma timeline (V1/A1) a partir do Media Pool e reproduzi-la com o áudio como relógio mestre, mantendo vídeo e áudio a menos de 1 quadro de distância por 10 minutos.

**Architecture:** `mcs_core` ganha o modelo de timeline e as conversões quadro↔amostra. `mcs_media` ganha `AudioDecoder` (FFmpeg + swresample → estéreo float 48 kHz) e um caminho rápido sequencial no `FrameDecoder`. Novo `mcs_playback`: `TimelineVideo` (quadro da timeline → imagem), `TimelineAudio` (mixer), `PlaybackEngine` (buffer circular SPSC; `fillAhead()` na thread de alimentação, `pull()` na thread de áudio; relógio = amostras entregues − latência), `AudioOutput` (miniaudio) e `Player` (junta tudo; relógio de fallback sem dispositivo). A UI ganha `TimelineView` (QPainter), viewer de programa e append/play.

**Tech Stack:** C++20, Qt 6.11.3 (Core, Gui, Widgets, Concurrent, Test), FFmpeg 9.0.2 (avformat, avcodec, swscale, swresample) e miniaudio 0.11.25 via vcpkg.

**Spec:** [docs/superpowers/specs/2026-10-13-mcs-ai-editor-design.md](../specs/2026-10-13-mcs-ai-editor-design.md) — marco v0.3 (seção 9), seções 5.2 (threads e relógio), 6.5 (áudio), 7 (modelo), 8 (interface), 10 (testes). Stack de áudio e remanejamento GPU→v0.6 / HW→v0.8 atualizados na spec em 2026-10-13.

## Decisões deste plano

- **Relógio = áudio entregue ao dispositivo − latência.** Underrun (buffer vazio) entrega silêncio e **não avança** o relógio: o vídeo espera o áudio, nunca dessincroniza.
- **Motor testável sem threads nem placa de som:** `fillAhead()`/`pull()` são chamados direto pelos testes com tempo virtual. O teste de 10 minutos roda em segundos.
- **Viewer de programa e decode na thread da GUI** (CPU, `QPainter`), com caminho rápido sequencial no decoder (sem seek ao avançar). *Teto conhecido:* 4K/HEVC pode não acompanhar; prefetch em worker + decode HW no v0.8.
- **Timeline nova adota o fps do primeiro vídeo** adicionado; clipes de fps diferente usam o quadro mais próximo (spec 7.2).
- **UI mínima:** append no fim (duplo clique no Media Pool ou Shift+F12), Espaço = play/pause, clique/arrasto na régua da timeline = seek. Edição de verdade é o v0.4.

## Review Focus

1. **Clipe com fps diferente da timeline** (ex.: 50 fps numa timeline de 25): quadro e áudio certos, duração convertida → Task 1 (`sourceFrameAtDifferentFps`, `appendMediaRescalesDuration`).
2. **Sem dispositivo de áudio** (servidor, fone desconectado, backend falha): o playback avança pelo relógio do sistema → Task 5 (`noDeviceUsesFallbackClock`).
3. **Lacunas na timeline** (trecho sem clipe): áudio em silêncio e vídeo preto, sem crash → Task 3 (`gapIsNullImage`) e Task 4 (`gapIsSilence`).
4. **Buffer de áudio vazio (underrun)**: silêncio, relógio para e não dessincroniza → Task 4 (`underrunStallsClock`).
5. **Play no fim da timeline / seek durante playback**: recomeça do início; seek reposiciona áudio e vídeo juntos → Task 5 (`seekWhilePlayingRepositions`) e Task 6 (`playAtEndRestartsFromZero`).

```cpp
#pragma once

#include "core/media_info.h"
#include "core/rational.h"

#include <QString>
#include <QUuid>
#include <cstdint>
#include <vector>

namespace mcs::core {

// Clipe na timeline: start/duration em quadros da timeline; sourceIn em quadros da fonte.
struct Clip {
    QUuid id;
    QString path;
    Rational sourceFps; // fps da mídia (ou da timeline para clipe só de áudio)
    std::int64_t start = 0;
    std::int64_t duration = 0;
    std::int64_t sourceIn = 0;

    std::int64_t end() const { return start + duration; }
};

// Clipes ordenados por start, sem sobreposição.
struct Track {
    std::vector<Clip> clips;
    std::int64_t end() const;
};

struct Timeline {
    Rational fps{25, 1};
    std::vector<Track> video{Track{}}; // V1
    std::vector<Track> audio{Track{}}; // A1
    std::int64_t duration() const;     // fim do último clipe em qualquer trilha
};

// Clipe que cobre `frame` ([start, end)), ou nullptr.
const Clip* clipAt(const Track& track, std::int64_t frame);

// Primeira amostra do quadro (teto) e quadro de uma amostra (piso).
std::int64_t frameToSample(std::int64_t frame, Rational fps, int sampleRate);
std::int64_t sampleToFrame(std::int64_t sample, Rational fps, int sampleRate);

// Quadro da fonte exibido no quadro `frame` da timeline (quadro mais próximo).
std::int64_t sourceFrameAt(const Clip& clip, std::int64_t frame, Rational timelineFps);

// Amostra da fonte que soa na amostra `timelineSample` da timeline.
std::int64_t sourceSampleAt(const Clip& clip, std::int64_t timelineSample, Rational timelineFps,
                            int sampleRate);

// Acrescenta a mídia no fim: vídeo em V1, áudio em A1, mesmo início. Timeline vazia adota o
// fps do vídeo. Retorna o quadro inicial, ou -1 se a mídia não tem vídeo nem áudio.
std::int64_t appendMedia(Timeline& timeline, const MediaInfo& info);

} // namespace mcs::core
```

```cpp
#include "core/timeline.h"

#include <algorithm>
#include <cmath>

namespace mcs::core {

namespace {
// round(a / b) para a >= 0, b > 0.
std::int64_t divRound(std::int64_t a, std::int64_t b) { return (2 * a + b) / (2 * b); }
} // namespace

std::int64_t Track::end() const { return clips.empty() ? 0 : clips.back().end(); }

std::int64_t Timeline::duration() const {
    std::int64_t d = 0;
    for (const Track& t : video) {
        d = std::max(d, t.end());
    }
    for (const Track& t : audio) {
        d = std::max(d, t.end());
    }
    return d;
}

const Clip* clipAt(const Track& track, std::int64_t frame) {
    for (const Clip& c : track.clips) {
        if (frame >= c.start && frame < c.end()) {
            return &c;
        }
    }
    return nullptr;
}

std::int64_t frameToSample(std::int64_t frame, Rational fps, int sampleRate) {
    const std::int64_t num = frame * sampleRate * fps.den;
    return (num + fps.num - 1) / fps.num;
}

std::int64_t sampleToFrame(std::int64_t sample, Rational fps, int sampleRate) {
    return sample * fps.num / (static_cast<std::int64_t>(sampleRate) * fps.den);
}

std::int64_t sourceFrameAt(const Clip& clip, std::int64_t frame, Rational timelineFps) {
    const std::int64_t offset = std::max<std::int64_t>(0, frame - clip.start);
    return clip.sourceIn + divRound(offset * clip.sourceFps.num * timelineFps.den,
                                    clip.sourceFps.den * timelineFps.num);
}

std::int64_t sourceSampleAt(const Clip& clip, std::int64_t timelineSample, Rational timelineFps,
                            int sampleRate) {
    return frameToSample(clip.sourceIn, clip.sourceFps, sampleRate) +
           (timelineSample - frameToSample(clip.start, timelineFps, sampleRate));
}

std::int64_t appendMedia(Timeline& timeline, const MediaInfo& info) {
    if (!info.video && !info.audio) {
        return -1;
    }
    if (timeline.duration() == 0 && info.video && info.video->fps.num > 0) {
        timeline.fps = info.video->fps;
    }
    const Rational tl = timeline.fps;
    const std::int64_t start = std::max(timeline.video[0].end(), timeline.audio[0].end());

    std::int64_t duration = 0;
    Rational sourceFps = tl;
    if (info.video && info.video->fps.num > 0) {
        sourceFps = info.video->fps;
        duration = divRound(info.video->frameCount * tl.num * sourceFps.den, tl.den * sourceFps.num);
    } else {
        duration = std::llround(info.durationSeconds * tl.toDouble());
    }

    if (info.video) {
        timeline.video[0].clips.push_back(
            Clip{QUuid::createUuid(), info.path, sourceFps, start, duration, 0});
    }
    if (info.audio) {
        timeline.audio[0].clips.push_back(
            Clip{QUuid::createUuid(), info.path, sourceFps, start, duration, 0});
    }
    return start;
}

} // namespace mcs::core
```

```cpp
#include <QCoreApplication>
#include <QFileInfo>
#include <algorithm>
#include <vector>

extern "C" {
#include <libavcodec/avcodec.h>
#include <libavformat/avformat.h>
#include <libavutil/channel_layout.h>
#include <libswresample/swresample.h>
}

namespace mcs::media {

struct AudioDecoder::Impl {
    AVFormatContext* fmt = nullptr;
    AVCodecContext* dec = nullptr;
    SwrContext* swr = nullptr;
    AVFrame* frame = nullptr;
    AVPacket* pkt = nullptr;
    AVStream* st = nullptr;
    int streamIndex = -1;
    std::int64_t startPts = 0;
    std::int64_t length = 0;
    std::vector<float> buf;      // amostras decodificadas, intercaladas
    std::int64_t bufStart = -1;  // amostra de buf[0]; -1 = desconhecida (após seek)
    bool draining = false;

    ~Impl() {
        swr_free(&swr);
        av_frame_free(&frame);
        av_packet_free(&pkt);
        avcodec_free_context(&dec);
        avformat_close_input(&fmt);
    }

    std::int64_t bufFrames() const { return static_cast<std::int64_t>(buf.size()) / kChannels; }

    void seekTo(std::int64_t pos) {
        const std::int64_t ts =
            startPts + av_rescale_q(pos, AVRational{1, kSampleRate}, st->time_base);
        av_seek_frame(fmt, streamIndex, ts, AVSEEK_FLAG_BACKWARD);
        avcodec_flush_buffers(dec);
        swr_close(swr);
        swr_init(swr);
        buf.clear();
        bufStart = -1;
        draining = false;
    }

    void append(const AVFrame* f) {
        if (bufStart < 0) {
            std::int64_t pts = f->best_effort_timestamp;
            if (pts == AV_NOPTS_VALUE) {
                pts = f->pts;
            }
            bufStart = pts == AV_NOPTS_VALUE
                           ? 0
                           : av_rescale_q(pts - startPts, st->time_base, AVRational{1, kSampleRate});
        }
        const int capacity = swr_get_out_samples(swr, f->nb_samples);
        if (capacity <= 0) {
            return;
        }
        const std::size_t old = buf.size();
        buf.resize(old + static_cast<std::size_t>(capacity) * kChannels);
        auto* out = reinterpret_cast<uint8_t*>(buf.data() + old);
        const int got = swr_convert(swr, &out, capacity, f->extended_data, f->nb_samples);
        buf.resize(old + static_cast<std::size_t>(std::max(got, 0)) * kChannels);
    }

    // Decodifica mais um bloco em buf. false no fim do stream.
    bool decodeMore() {
        for (;;) {
            const int r = avcodec_receive_frame(dec, frame);
            if (r == 0) {
                append(frame);
                av_frame_unref(frame);
                return true;
            }
            if (r != AVERROR(EAGAIN) || draining) {
                return false;
            }
            if (av_read_frame(fmt, pkt) < 0) {
                avcodec_send_packet(dec, nullptr);
                draining = true;
                continue;
            }
            if (pkt->stream_index == streamIndex) {
                avcodec_send_packet(dec, pkt);
            }
            av_packet_unref(pkt);
        }
    }
};

AudioDecoder::AudioDecoder() = default;
AudioDecoder::~AudioDecoder() = default;

bool AudioDecoder::open(const QString& path, QString* error) {
    d_ = std::make_unique<Impl>();
    auto fail = [&](const char* text) {
        if (error) {
            *error = QCoreApplication::translate("mcs::media", text).arg(QFileInfo(path).fileName());
        }
        d_.reset();
        return false;
    };
    const QByteArray utf8 = path.toUtf8();
    if (avformat_open_input(&d_->fmt, utf8.constData(), nullptr, nullptr) < 0) {
        return fail("Cannot open \"%1\" as media.");
    }
    if (avformat_find_stream_info(d_->fmt, nullptr) < 0) {
        return fail("\"%1\" has no readable streams.");
    }
    const AVCodec* codec = nullptr;
    d_->streamIndex = av_find_best_stream(d_->fmt, AVMEDIA_TYPE_AUDIO, -1, -1, &codec, 0);
    if (d_->streamIndex < 0 || !codec) {
        return fail("\"%1\" has no audio.");
    }
    d_->st = d_->fmt->streams[d_->streamIndex];
    d_->dec = avcodec_alloc_context3(codec);
    if (!d_->dec || avcodec_parameters_to_context(d_->dec, d_->st->codecpar) < 0 ||
        avcodec_open2(d_->dec, codec, nullptr) < 0) {
        return fail("Cannot open the audio decoder for \"%1\".");
    }
    if (d_->dec->ch_layout.order == AV_CHANNEL_ORDER_UNSPEC) {
        av_channel_layout_default(&d_->dec->ch_layout, d_->dec->ch_layout.nb_channels);
    }
    AVChannelLayout stereo;
    av_channel_layout_default(&stereo, kChannels);
    if (swr_alloc_set_opts2(&d_->swr, &stereo, AV_SAMPLE_FMT_FLT, kSampleRate,
                            &d_->dec->ch_layout, d_->dec->sample_fmt, d_->dec->sample_rate, 0,
                            nullptr) < 0 ||
        swr_init(d_->swr) < 0) {
        return fail("Cannot convert the audio of \"%1\".");
    }
    d_->startPts = d_->st->start_time != AV_NOPTS_VALUE ? d_->st->start_time : 0;
    if (d_->st->duration != AV_NOPTS_VALUE) {
        d_->length = av_rescale_q(d_->st->duration, d_->st->time_base, AVRational{1, kSampleRate});
    } else if (d_->fmt->duration != AV_NOPTS_VALUE) {
        d_->length = av_rescale_q(d_->fmt->duration, AVRational{1, AV_TIME_BASE},
                                  AVRational{1, kSampleRate});
    }
    d_->frame = av_frame_alloc();
    d_->pkt = av_packet_alloc();
    return true;
}

bool AudioDecoder::isOpen() const { return d_ != nullptr; }

std::int64_t AudioDecoder::length() const { return d_ ? d_->length : 0; }

void AudioDecoder::read(std::int64_t position, float* out, int frames) {
    std::fill(out, out + static_cast<std::ptrdiff_t>(frames) * kChannels, 0.0f);
    if (!d_ || frames <= 0) {
        return;
    }
    Impl& s = *d_;
    // Parte negativa: silêncio.
    int written = static_cast<int>(std::clamp<std::int64_t>(-position, 0, frames));
    const std::int64_t first = position + written;
    // Até 1 s à frente do que já está decodificado: continua em sequência; senão, seek.
    const bool reachable = s.bufStart >= 0 && first >= s.bufStart &&
                           first <= s.bufStart + s.bufFrames() + kSampleRate;
    if (!reachable && written < frames) {
        s.seekTo(first);
    }
    while (written < frames) {
        const std::int64_t pos = position + written;
        if (s.bufStart >= 0) {
            const std::int64_t bufEnd = s.bufStart + s.bufFrames();
            if (pos < s.bufStart) { // seek caiu depois do alvo: silêncio até os dados
                written += static_cast<int>(std::min<std::int64_t>(s.bufStart - pos, frames - written));
                continue;
            }
            if (pos < bufEnd) {
                const int n = static_cast<int>(std::min<std::int64_t>(bufEnd - pos, frames - written));
                const auto offset = static_cast<std::size_t>((pos - s.bufStart) * kChannels);
                std::copy_n(s.buf.begin() + static_cast<std::ptrdiff_t>(offset), n * kChannels,
                            out + static_cast<std::ptrdiff_t>(written) * kChannels);
                written += n;
                continue;
            }
            // Já consumido: descarta mantendo a posição contínua.
            s.buf.clear();
            s.bufStart = bufEnd;
        }
        if (!s.decodeMore()) {
            break; // fim do stream: o resto fica em silêncio
        }
    }
}

} // namespace mcs::media
```

```cpp
namespace mcs::playback {

TimelineVideo::TimelineVideo() = default;
TimelineVideo::~TimelineVideo() = default;

void TimelineVideo::setTimeline(const core::Timeline& timeline) {
    timeline_ = timeline;
    lastFrame_ = -1;
    lastImage_ = {};
}

media::FrameDecoder* TimelineVideo::decoderFor(const QString& path) {
    auto it = decoders_.find(path);
    if (it == decoders_.end()) {
        auto decoder = std::make_unique<media::FrameDecoder>();
        if (!decoder->open(path)) {
            decoder.reset(); // guarda a falha para não tentar abrir a cada quadro
        }
        it = decoders_.emplace(path, std::move(decoder)).first;
    }
    return it->second.get();
}

QImage TimelineVideo::frameAt(std::int64_t frame) {
    if (frame == lastFrame_) {
        return lastImage_;
    }
    QImage image;
    for (auto track = timeline_.video.rbegin(); track != timeline_.video.rend(); ++track) {
        const core::Clip* clip = core::clipAt(*track, frame);
        if (!clip) {
            continue;
        }
        if (media::FrameDecoder* decoder = decoderFor(clip->path)) {
            const auto decoded = decoder->frameAt(core::sourceFrameAt(*clip, frame, timeline_.fps));
            if (decoded) {
                image = decoded->image;
            }
        }
        break;
    }
    lastFrame_ = frame;
    lastImage_ = image;
    return image;
}

} // namespace mcs::playback
```

```cpp
TimelineAudio::TimelineAudio() = default;

void TimelineAudio::setTimeline(const core::Timeline& timeline) { timeline_ = timeline; }

AudioDecoder* TimelineAudio::decoderFor(const QString& path) {
    auto it = decoders_.find(path);
    if (it == decoders_.end()) {
        auto decoder = std::make_unique<AudioDecoder>();
        if (!decoder->open(path)) {
            decoder.reset();
        }
        it = decoders_.emplace(path, std::move(decoder)).first;
    }
    return it->second.get();
}

void TimelineAudio::render(std::int64_t position, float* out, int frames) {
    constexpr int ch = AudioDecoder::kChannels;
    constexpr int rate = AudioDecoder::kSampleRate;
    std::fill(out, out + static_cast<std::ptrdiff_t>(frames) * ch, 0.0f);
    scratch_.resize(static_cast<std::size_t>(frames) * ch);
    const std::int64_t end = position + frames;
    // ponytail: varre todos os clipes a cada bloco; índice por tempo se timelines grandes pesarem.
    for (const core::Track& track : timeline_.audio) {
        for (const core::Clip& clip : track.clips) {
            const std::int64_t from =
                std::max(core::frameToSample(clip.start, timeline_.fps, rate), position);
            const std::int64_t to =
                std::min(core::frameToSample(clip.end(), timeline_.fps, rate), end);
            if (from >= to) {
                continue;
            }
            AudioDecoder* decoder = decoderFor(clip.path);
            if (!decoder) {
                continue;
            }
            const int n = static_cast<int>(to - from);
            decoder->read(core::sourceSampleAt(clip, from, timeline_.fps, rate), scratch_.data(), n);
            float* dst = out + (from - position) * ch;
            for (int i = 0; i < n * ch; ++i) {
                dst[i] += scratch_[static_cast<std::size_t>(i)];
            }
        }
    }
}
```

```cpp
#include "core/timeline.h"

namespace mcs::playback {

// Coração do playback. O áudio é o relógio mestre:
//   fillAhead() — thread de alimentação: mixa a timeline num buffer circular (SPSC);
//   pull()      — thread de áudio: entrega amostras ao dispositivo (silêncio se faltar);
//   currentFrame() — qualquer thread: quadro do áudio que está soando (entregue − latência).
// Underrun não avança o relógio: o vídeo espera o áudio. setTimeline/seek só com a saída parada.
class PlaybackEngine {
public:
    explicit PlaybackEngine(int ringFrames = 24000); // 0,5 s a 48 kHz

    void setTimeline(const core::Timeline& timeline);
    void seek(std::int64_t frame);
    void fillAhead();
    void pull(float* out, int frames);
    void setOutputLatency(int frames);

    std::int64_t currentFrame() const;
    std::int64_t deliveredFrames() const;
    std::int64_t underruns() const;
    core::Rational fps() const;

private:
    core::Timeline timeline_;
    TimelineAudio audio_;
    std::vector<float> ring_;
    std::vector<float> chunk_;
    std::int64_t capacity_;
    std::int64_t seekFrame_ = 0;
    std::int64_t seekSample_ = 0;
    std::atomic<std::int64_t> written_{0};
    std::atomic<std::int64_t> read_{0};
    std::atomic<std::int64_t> underruns_{0};
    std::atomic<int> latency_{0};
};

} // namespace mcs::playback
```

```cpp
#include "playback/playback_engine.h"

#include "media/audio_decoder.h"

#include <algorithm>

namespace mcs::playback {

namespace {
constexpr int kCh = media::AudioDecoder::kChannels;
constexpr int kRate = media::AudioDecoder::kSampleRate;
constexpr int kChunk = 1024;
} // namespace

PlaybackEngine::PlaybackEngine(int ringFrames)
    : ring_(static_cast<std::size_t>(ringFrames) * kCh), capacity_(ringFrames) {}

void PlaybackEngine::setTimeline(const core::Timeline& timeline) {
    timeline_ = timeline;
    audio_.setTimeline(timeline);
    seek(seekFrame_);
}

void PlaybackEngine::seek(std::int64_t frame) {
    seekFrame_ = std::max<std::int64_t>(0, frame);
    seekSample_ = core::frameToSample(seekFrame_, timeline_.fps, kRate);
    written_.store(0);
    read_.store(0);
}

void PlaybackEngine::setOutputLatency(int frames) { latency_.store(std::max(0, frames)); }

void PlaybackEngine::fillAhead() {
    const std::int64_t r = read_.load(std::memory_order_acquire);
    std::int64_t w = written_.load(std::memory_order_relaxed);
    while (w - r < capacity_) {
        const int n = static_cast<int>(std::min<std::int64_t>(kChunk, capacity_ - (w - r)));
        chunk_.resize(static_cast<std::size_t>(n) * kCh);
        audio_.render(seekSample_ + w, chunk_.data(), n);
        for (int i = 0; i < n; ++i) {
            const auto slot = static_cast<std::size_t>((w + i) % capacity_) * kCh;
            ring_[slot] = chunk_[static_cast<std::size_t>(i) * kCh];
            ring_[slot + 1] = chunk_[static_cast<std::size_t>(i) * kCh + 1];
        }
        w += n;
        written_.store(w, std::memory_order_release);
    }
}

void PlaybackEngine::pull(float* out, int frames) {
    const std::int64_t w = written_.load(std::memory_order_acquire);
    const std::int64_t r = read_.load(std::memory_order_relaxed);
    const int n = static_cast<int>(std::min<std::int64_t>(frames, w - r));
    for (int i = 0; i < n; ++i) {
        const auto slot = static_cast<std::size_t>((r + i) % capacity_) * kCh;
        out[i * kCh] = ring_[slot];
        out[i * kCh + 1] = ring_[slot + 1];
    }
    std::fill(out + static_cast<std::ptrdiff_t>(n) * kCh,
              out + static_cast<std::ptrdiff_t>(frames) * kCh, 0.0f);
    if (n < frames) {
        underruns_.fetch_add(1, std::memory_order_relaxed);
    }
    read_.store(r + n, std::memory_order_release);
}

std::int64_t PlaybackEngine::currentFrame() const {
    const std::int64_t heard =
        std::max<std::int64_t>(0, read_.load(std::memory_order_acquire) - latency_.load());
    return std::max(seekFrame_, core::sampleToFrame(seekSample_ + heard, timeline_.fps, kRate));
}

std::int64_t PlaybackEngine::deliveredFrames() const { return read_.load(); }

std::int64_t PlaybackEngine::underruns() const { return underruns_.load(); }

core::Rational PlaybackEngine::fps() const { return timeline_.fps; }

} // namespace mcs::playback
```

```cpp
#include <miniaudio.h>

namespace mcs::playback {

struct AudioOutput::Impl {
    ma_context context{};
    ma_device device{};
    bool hasContext = false;
    bool running = false;
    int latency = 0;
};

namespace {
void onAudio(ma_device* device, void* output, const void*, ma_uint32 frames) {
    static_cast<PlaybackEngine*>(device->pUserData)
        ->pull(static_cast<float*>(output), static_cast<int>(frames));
}
} // namespace

AudioOutput::AudioOutput(PlaybackEngine& engine)
    : engine_(engine), d_(std::make_unique<Impl>()) {}

AudioOutput::~AudioOutput() { stop(); }

bool AudioOutput::start(Backend backend, QString* error) {
    stop();
    auto fail = [&](const char* text) {
        if (error) {
            *error = QCoreApplication::translate("mcs::playback", text);
        }
        stop();
        return false;
    };
    if (backend == Backend::None) {
        return fail("No audio device selected.");
    }
    ma_context* context = nullptr;
    if (backend == Backend::Null) {
        const ma_backend backends[] = {ma_backend_null};
        if (ma_context_init(backends, 1, nullptr, &d_->context) != MA_SUCCESS) {
            return fail("Cannot initialize the audio system.");
        }
        d_->hasContext = true;
        context = &d_->context;
    }
    ma_device_config config = ma_device_config_init(ma_device_type_playback);
    config.playback.format = ma_format_f32;
    config.playback.channels = media::AudioDecoder::kChannels;
    config.sampleRate = media::AudioDecoder::kSampleRate;
    config.dataCallback = onAudio;
    config.pUserData = &engine_;
    if (ma_device_init(context, &config, &d_->device) != MA_SUCCESS) {
        return fail("Cannot open the audio device.");
    }
    d_->running = true; // a partir daqui stop() precisa desligar o device
    d_->latency = static_cast<int>(d_->device.playback.internalPeriodSizeInFrames *
                                   d_->device.playback.internalPeriods);
    engine_.setOutputLatency(d_->latency);
    if (ma_device_start(&d_->device) != MA_SUCCESS) {
        return fail("Cannot start the audio device.");
    }
    return true;
}

void AudioOutput::stop() {
    if (d_->running) {
        ma_device_uninit(&d_->device); // para e espera o callback terminar
        d_->running = false;
    }
    if (d_->hasContext) {
        ma_context_uninit(&d_->context);
        d_->hasContext = false;
    }
}

bool AudioOutput::isRunning() const { return d_->running; }

int AudioOutput::latencyFrames() const { return d_->latency; }
```

```cpp
}

void Player::play() {
    if (playing_) {
        return;
    }
    engine_.seek(pausedFrame_);
    engine_.fillAhead(); // buffer cheio antes do primeiro callback
    fallback_ = !output_.start(backend_);
    if (fallback_) {
        fallbackTimer_.start();
    } else {
        feeding_.store(true);
        feeder_ = std::thread([this] {
            while (feeding_.load()) {
                engine_.fillAhead();
                std::this_thread::sleep_for(std::chrono::milliseconds(5));
            }
        });
    }
    playing_ = true;
    emit playingChanged(true);
}

void Player::pause() {
    if (!playing_) {
        return;
    }
    pausedFrame_ = currentFrame();
    output_.stop();
    stopFeeder();
    playing_ = false;
    emit playingChanged(false);
}

void Player::stopFeeder() {
    feeding_.store(false);
    if (feeder_.joinable()) {
        feeder_.join();
    }
}

bool Player::isPlaying() const { return playing_; }

void Player::seek(std::int64_t frame) {
    const bool wasPlaying = playing_;
    pause();
    pausedFrame_ = std::max<std::int64_t>(0, frame);
    if (wasPlaying) {
        play();
    }
}

std::int64_t Player::currentFrame() const {
    if (!playing_) {
        return pausedFrame_;
    }
    if (fallback_) {
        const core::Rational fps = engine_.fps();
        return pausedFrame_ + fallbackTimer_.elapsed() * fps.num / (1000 * fps.den);
    }
    return engine_.currentFrame();
}

bool Player::usingFallbackClock() const { return playing_ && fallback_; }

} // namespace mcs::playback
```

```cpp
void TimelineView::paintEvent(QPaintEvent*) {
    QPainter p(this);
    p.fillRect(rect(), QColor(0x18, 0x18, 0x18));

    // Régua: um traço por segundo.
    p.fillRect(QRect(0, 0, width(), kRulerHeight), QColor(0x22, 0x22, 0x22));
    p.setPen(QColor(0x80, 0x80, 0x80));
    const auto fpsNominal = static_cast<std::int64_t>(
        std::max<long long>(1, std::llround(timeline_ ? timeline_->fps.toDouble() : 25.0)));
    for (std::int64_t f = 0; xForFrame(f) < width(); f += fpsNominal) {
        p.drawLine(xForFrame(f), kRulerHeight - 6, xForFrame(f), kRulerHeight);
    }

    // Trilhas: V1.. e depois A1..
    const std::size_t videoTracks = timeline_ ? timeline_->video.size() : 1;
    const std::size_t audioTracks = timeline_ ? timeline_->audio.size() : 1;
    auto drawTrack = [&](int row, const QString& label, const core::Track* track, QColor color) {
        const int y = kRulerHeight + row * kTrackHeight;
        p.setPen(QColor(0x30, 0x30, 0x30));
        p.drawLine(0, y + kTrackHeight - 1, width(), y + kTrackHeight - 1);
        p.setPen(QColor(0xc0, 0xc0, 0xc0));
        p.drawText(QRect(0, y, kHeaderWidth, kTrackHeight), Qt::AlignCenter, label);
        if (!track) {
            return;
        }
        for (const core::Clip& clip : track->clips) {
            const QRect r(xForFrame(clip.start), y + 3,
                          std::max(1, xForFrame(clip.end()) - xForFrame(clip.start)),
                          kTrackHeight - 6);
            p.fillRect(r, color);
            p.setPen(QColor(0x10, 0x10, 0x10));
            p.drawText(r.adjusted(4, 0, -2, 0), Qt::AlignVCenter | Qt::AlignLeft,
                       QFileInfo(clip.path).fileName());
        }
    };
    int row = 0;
    for (std::size_t i = 0; i < videoTracks; ++i) {
        drawTrack(row++, QStringLiteral("V%1").arg(i + 1),
                  timeline_ ? &timeline_->video[i] : nullptr, QColor(0x4a, 0x7d, 0xb8));
    }
    for (std::size_t i = 0; i < audioTracks; ++i) {
        drawTrack(row++, QStringLiteral("A%1").arg(i + 1),
                  timeline_ ? &timeline_->audio[i] : nullptr, QColor(0x4f, 0xa8, 0x6a));
    }

    // Playhead.
    p.setPen(QPen(QColor(0xe0, 0x4a, 0x3a), 2));
    p.drawLine(xForFrame(playhead_), 0, xForFrame(playhead_), height());
}
```
